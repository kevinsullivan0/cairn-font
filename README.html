Regular, Italic, Bold, and Bold Italic. Two families: Cairn for prose and Cairn Mono for code, each in four real styles.

Use it in your next HTML file

Copy the web folder beside your HTML file. Add this in the document head:

<link rel="stylesheet" href="web/cairn.css">

Then use the family where you want it:

<article class="cairn-prose">
  <h1>The last watch</h1>
  <p>Words with <strong>weight</strong>
     and <em>emphasis</em>.</p>
  <p class="cairn-numbers">01:11 / 08:48</p>
</article>

The stylesheet selects the real bold and italic fonts, with kerning and fallback fonts configured. Use class="cairn" for your own text sizes, or class="cairn-prose" for 18 px text with comfortable line spacing.

Editable HTML starter · Font stylesheet · Portable stylesheet with embedded fonts

For a single-file HTML document, put the contents of cairn-embedded.css into a <style> element. This avoids separate font-file paths. The specimen already works this way.

Code blocks

Add web/cairn-mono.css to your HTML and use class="cairn-code" on code blocks. Or use web/cairn-mono-embedded.css for portable HTML. Every supported character has the same width, with real bold and italic styles.

Desktop fonts

The desktop folder contains:

  • Cairn Regular
  • Cairn Italic
  • Cairn Bold
  • Cairn Bold Italic
  • Cairn Mono Regular, Italic, Bold, and Bold Italic — also in desktop/

On a Mac, open the desired files in Font Book and review them. Choose Install only when you want to add them. Applications should then offer the Cairn family with four styles. No installation is needed to try the HTML specimen.

What to expect

Start at 18 px for prose or 16 px for interfaces. All printable ASCII, useful smart punctuation, and the original symbol repertoire are included. Accent letters and other scripts use fallback fonts. The inherited ornaments have been removed. Parentheses are drawn with curved middles and sharp cut ends.

All four styles passed outline, spacing, shaping, and small-size checks. macOS decoded and rendered the fonts. Cairn Mono also passed native monospace recognition and equal-advance checks. Browser layouts and Windows rendering have not been visually tested; manual font hinting remains outside this first edition.

Personal edition

All included glyphs are generated from Cairn’s own drawing definitions. No inherited Elbjorg ornaments or reference font are included. The complete documentation records provenance, coverage, validation, and rebuilding instructions. No distribution license has yet been selected.

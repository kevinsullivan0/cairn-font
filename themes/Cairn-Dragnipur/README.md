# Cairn / Dragnipur — early palette studies

Earlier Ember (dark) and Vellum (light) color studies, plus Amber Ash, Bronze Dusk,
and Weathered Stone mockups. The current finished direction is
[Hearthstone / Cairn Ash](../Cairn-Ash/README.md).

Open `preview.html` or `amber-studies.html` for local interactive comparisons.
The desktop painting used during color exploration has been removed; only the
extracted colors and original interface samples are included.

Copy `obsidian/Cairn Dragnipur` into a vault’s `.obsidian/themes/` and select it
in Appearance to try the earlier theme. Install Cairn and Cairn Mono from the
root `desktop/` directory first. The optional `obsidian/cairn-reading.css` snippet
tries Cairn in prose. Kitty launchers and configurations are included, along with
Omarchy color exports under `omarchy/`.

Palette extraction used [Aether](https://github.com/omacom/aether), pinned at
`29d07b1a8f474c77bf02aece948373f40abed105`. Its output is in
`aether-extraction.json`; the small adapter in `source/aether-extract.go` runs
inside that Aether checkout. No upstream source or artwork is redistributed.

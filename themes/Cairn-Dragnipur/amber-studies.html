The terminal stays simple

The Obsidian studies add copper titles, gold bold text, sage italics, six heading colors, and restrained double-cut borders. The terminal uses the existing Ember colors and Cairn Mono, without the archive decoration.

To open the terminal trials: in Finder, press ⌘⇧G, paste this folder path, and press Return. Then double-click Try Ember.command or Try Vellum.command.

Browser links can display the launcher as text. Open the actual file from Finder. These launchers still use the existing terminal palettes.

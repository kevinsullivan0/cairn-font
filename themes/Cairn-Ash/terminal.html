The same text in both schemes. Font fallback depends on what is installed. Cairn Mono is embedded for a quick trial; Kitty launchers offer JetBrains Mono or Cairn Mono at 12 pt.

Try it

  1. In Finder, open this folder.
  2. Double-click Try Hearthstone.command for JetBrains Mono, or Try Hearthstone + Cairn Mono.command for Cairn Mono.
  3. Try your usual commands. Close that Kitty window when finished.

Both are separate trials at 12 pt. Your existing windows and saved Kitty settings are preserved. The Cairn Mono launcher overrides the font only for that trial. Try Limestone.command remains available for the light palette.

Already have a Kitty setup? The color-only files preserve your font and window settings. Add an include for the chosen file in your own configuration when you want to use it.

The same text in both schemes. Font fallback depends on what is installed. Cairn Mono is embedded for a quick trial; Kitty launchers keep JetBrains Mono at 12 pt.

Try it

In Finder, double-click Try Hearthstone.command or Try Limestone.command in this folder. Each opens a separate Kitty trial window. Close it to return.

Already have a Kitty setup? The color-only files preserve your font and window settings. Add an include for the chosen file in your own configuration when you want to use it.
